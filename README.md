# Portafolio · Daniela Magaña

Sitio web personal donde presento mi perfil profesional y mis proyectos como **Full Stack Developer**.

## 🛠️ Tecnologías

HTML5 · CSS3 · Bootstrap 5 · Git/GitHub

## ✨ Características

- Diseño responsivo con Bootstrap
- Paleta propia en tonos verdes y azules
- Secciones de perfil, habilidades, proyectos y contacto

## ▶️ Cómo verlo

​```bash
git clone https://github.com/danielamag98/Portafolio-web.git
cd Portafolio-web
npm install
​```

Después abre `index.html` en tu navegador.
